## Реализация

- [x] Предусмотрены классы `ConverterJSON`, `InvertedIndex`, `SearchServer` и структуры `Entry`, `RelativeIndex`.
- [x] Названия отражают назначение, не используют транслитерацию и произвольные сокращения. Обязательные имена интерфейсов сохранены по ТЗ; новые имена используют единый стиль внутри своей категории.
- [x] Предусмотрены чтение конфигурации, загрузка документов и запросов, запись ответов JSON.
- [x] Документы индексируются в отдельных рабочих потоках; число потоков ограничено аппаратной параллельностью и числом документов. Повторное обновление заменяет предыдущую базу.
- [x] Частоты слов сохраняются отдельно для каждого документа.
- [x] Основной поиск находит документы со всеми уникальными словами запроса; дополнительный режим `--match any` поддерживает частичные совпадения.
- [x] Релевантность определяется суммой частот и нормируется на максимум по найденным документам.
- [x] Результаты сортируются по убыванию рейтинга с устойчивым правилом для равных оценок.
- [x] Применяется `max_responses`, по умолчанию 5.
- [x] Общее количество совпадений до ограничения доступно через `GetResultCounts()`.
- [x] Формат `answers.json` использует последовательные идентификаторы запросов, `docid`, `rank` и строковый `result` согласно образцу ТЗ.
- [x] Отсутствующий документ не сдвигает идентификаторы остальных документов.
- [x] README содержит назначение проекта, стек, инструкции сборки и команды запуска после сборки.
- [x] Неоднозначности примеров `TestTop5`, `TestBasic2` и формата ответа раскрыты в README.
